XABARCHI -> APK (Android Studio kerak emas)
1. github.com da bepul akkaunt oching va yangi repository yarating (masalan: xabarchi).
2. 'uploading an existing file' orqali shu zip ichidagi HAMMA fayl va papkalarni yuklang
   (.github papkasi ham kirishi shart) va Commit bosing.
3. Repository -> Actions bolimi -> 'APK' ishga tushadi (3-5 daqiqa).
4. Tugagach (yashil galochka) ishga tushirishni oching, pastda 'Xabarchi-apk' ni yuklab oling,
   zipni oching -> app-debug.apk. Telefonga ornatib, 'noma'lum manba' ruxsatini bering.
